Elhub is Norway's national IT platform (datahub) for collecting and distributing electricity data, owned and operated by Elhub AS, a public company owned by Statnett SF. Grid companies, electricity suppliers and service providers use Elhub to exchange metering values and customer information for more than 4 million metering points, and it handles supplier switching and settlement processes. Households and businesses use Elhub Min side to view and share their own electricity data. The Elhub API Portal (api.elhub.no) offers public open-data APIs (Energy Data API, CC BY 4.0) and Maskinporten-protected APIs including Data Export, Market Data, Access, Settlement and Metering Values APIs.

**Areas:** Company · Energy · Electricity · Data Hub · Metering · Open Data · Norway · Utilities

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Elhub: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
